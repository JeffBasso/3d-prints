# Circular Drip Plate

A parametric circular drip plate designed for plant pots. Features a hexagonal standoff pattern to elevate the pot above collected water, a lofted rim, and an optional drain trough. Fully configurable via Onshape parameters.

## Features

- Parametric diameter — scale to any pot size
- Lofted and filleted outer rim
- 163-point hexagonal fill pattern standoffs to keep pot above water
- Toggleable drain trough with adjustable length
- Toggleable standoff pattern
- Chamfered feet for stable placement

## Configuration Parameters

| Parameter | Default | Description |
|-----------|---------|-------------|
| Diameter | 15 in | Overall plate diameter — adjust to match your pot |
| Rim Height | 0.5 in | Height of the outer rim |
| Rim Offset | 0.25 in | Inset of the rim from edge |
| Trough Length | 2 in | Length of the drain trough — adjustable |
| Trough | ✅ | Toggle drain trough on/off |
| Stand Offs | ✅ | Toggle hex standoff pattern on/off |

## Print Settings

- **Material:** PETG or ASA recommended — both handle outdoor and wet environments well. ASA preferred for prolonged UV exposure.
- No supports required
- Print flat side down

## Files

| File | Description |
|------|-------------|
| `circular-drip-plate.stl` | Default configuration (15 in diameter, trough and standoffs enabled) |
| `circular-drip-plate.step` | STEP file for modification in any CAD tool |
